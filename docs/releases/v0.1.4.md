# Auto-Test v0.1.4

- 全工作台的 62 个下拉入口共用样式，展开时有短过渡。悬停使用浅灰，当前选项带勾标。支持键盘操作、关闭时恢复焦点和系统减少动态效果设置。桌面内核采用同样外观。
- 版本及环境筛选项收为紧凑宽度。需求录入改为编号和标题同排、正文独占一行，操作放在表单底部。窄窗口使用单列。
- 「录制 UI 自动化用例」移至用例页。录制包含浏览器操作步骤，可导出草稿并从用例页导入。
- 结构化 UI 用例遇到控件名称漂移时，可由工作区模型在同作用域内提出一次恢复选择。原断言通过后生成候选补丁。执行记录展示验证过程，工作区所有者批准后写入新用例修订，可从审批记录查看来源执行和用例历史。
