# Auto-Test v0.1.2

- 「需求」支持上传 PDF、Word DOCX、Excel XLSX、UTF-8 CSV、Markdown 和 TXT。先解析预览，再导入当前项目。Excel 需求表可批量导入，普通表格可作为一条需求记录。PDF 扫描件可先做 OCR，旧版 `.doc` 和 `.xls` 可另存为现代格式。
- 「用例」新增接口与性能场景表单、修订历史、逐步截图选项，以及桌面 XLSX 导入导出。执行详情展示性能指标、步骤截图和 HTML 报告。
- 「缺陷」支持手动提交、调整严重级别和复测。「企业流程」支持七类产物的模型草稿与人工签核。「概览」新增环比和同比。
- 「设置」可激活桌面执行端并选择 Playwright 浏览器。「MCP 接入」支持管理令牌与查看客户端配置。模型草稿使用工作区配置的 OpenAI 兼容服务。
- Windows 快捷方式使用新的双环图标资源路径。覆盖安装会提示关闭旧版，保留现有工作区数据。旧的任务栏固定项仍显示历史图标时，可从更新后的开始菜单快捷方式重新固定。
