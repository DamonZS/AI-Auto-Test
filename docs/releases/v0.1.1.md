# Auto-Test v0.1.1

- Windows 安装和卸载界面默认使用简体中文。覆盖升级时，检测到旧版 Auto-Test 正在运行会提供「关闭后继续」和「取消安装」。确认关闭会退出旧版，再更新文件。关闭应用会中断正在执行的测试。
- Windows 与 macOS 的应用图标已换成公司双环 Logo。安装包、快捷方式、窗口和托盘统一使用新图标。
- 覆盖安装保留工作区和账号。升级时选择原安装目录，完成后重新打开 Auto-Test。首次安装仍可在桌面窗口注册管理员。

本版提供 Windows x64 安装程序、macOS Apple Silicon DMG、Linux amd64 容器镜像及 `SHA256SUMS.txt`。[安装与升级说明](https://github.com/DamonZS/Auto-Test/blob/v0.1.1/docs/deployment/README.md)
