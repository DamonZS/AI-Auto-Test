# Auto-Test v0.1.3

- 项目联通需求、版本、环境、用例和质量交付。支持项目编辑与统计、版本对比、环境级别和部署版本关联。
- 需求可通过 AI 拆分为功能点与验收标准。人工退回后，模型按反馈生成新一轮草稿。批准后可生成分类用例，经过审核、退回和 AI 修订后定稿。功能与防御性安全用例可以登记人工核验结果。
- 套件支持按项目组织和排序定稿的自动化用例。执行页支持按状态筛选并查看证据。缺陷详情包含发现与修复版本、责任人、复现步骤、预期与实际结果、处理历史和复测入口。
- 测试数据页支持勾选多个类别和独立字段，组合客户资料、登录认证、联系地址、订单及交易数据。选择条数后点击「生成并保存」，使用工作区模型生成合成记录并直接打开数据集。也可补充业务场景或使用原有规则生成方式。敏感字段在工作台遮码。
- 概览增加执行结果堆叠柱状图、通过率和新增缺陷折线、严重程度环形图、缺陷状态条形图。每日图表支持近 7、14、30 天，保留月度对比和明细。
- 侧栏与指标卡增加随应用分发的图标。Windows 和 macOS 桌面版支持覆盖升级。
- 「切换工作区」和「退出登录」固定在侧栏左下角。短窗口中的侧栏菜单可独立滚动。
