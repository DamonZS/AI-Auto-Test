# 单次执行报告导出

`GET /api/runs/{id}/report` 使用 Web Bearer 会话和 `X-Tenant-Id`。当前工作区的成员可导出该工作区的执行记录，包括只读成员。

在 `(*Server).Routes` 注册 `mux.HandleFunc("GET /api/runs/{id}/report", s.tenant(s.exportRunReport))`。工作台使用 `api.download` 发送会话和租户头，将返回的 Blob 保存为 `run-report.html`。用浏览器打开下载的 HTML，再通过打印功能保存 PDF。

| 响应 | 含义 |
| --- | --- |
| `200` | UTF-8 HTML 附件，`Cache-Control: no-store` |
| `400` | 缺少工作区头 |
| `401` | Web 会话缺失或无效 |
| `403` | 当前用户不是所选工作区的成员 |
| `404` | 当前工作区无对应执行记录 |
| `500` | 读取证据或生成报告失败 |

报告包含执行状态、耗时、执行时间、复核状态、已保存的断言摘要、步骤序号和动作、步骤状态及耗时，以及已记录的请求数、失败数、错误率、吞吐量和 P50/P95/P99。待执行记录和历史记录可导出已有信息。缺失的指标显示为 `—`，零值照常显示。

导出保留固定格式的 API 断言行、结构化 UI 断言计数和性能执行摘要。自然语言执行报告中没有匹配到固定格式时，显示「暂无断言报告」。非标准步骤动作显示「未知动作」。场景、测试数据、请求与响应原文、截图和其他证据原始数据不纳入附件。`html/template` 将持久化文本转义后显示，生成的附件可离线打开。
