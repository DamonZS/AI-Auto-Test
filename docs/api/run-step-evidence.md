# 结构化 UI 回放证据

执行端在现有 `POST /api/runs/{id}/finish` 请求中可以附带 `steps` 数组。每条记录包含从 1 开始的 `step`、步骤 `action`、`passed` 或 `failed` 的 `status` 和非负 `duration_ms`。失败步骤终止本次回放，未执行的步骤无记录。

Go 在结束执行的同一事务中，按租户和运行 ID 持久化有序证据。`GET /api/runs/{id}` 返回该数组，没有逐步证据的历史执行返回空数组。工作台在执行详情中展示步骤状态和耗时。测试数据值、填写内容及页面正文不属于本证据字段。

验收覆盖真实 Chromium 步骤执行、证据经完成接口写入并能重新加载、跨租户写入与读取被拒绝，以及 API 和性能旧执行端的兼容性。迁移仅创建新表，可在保留该表的情况下回滚应用程序。
